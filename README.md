# Site_Servicos_De_Streaming-PHP
*SaaS Tracker*

Sistema web para controle de assinaturas e serviços recorrentes (streaming, música, internet, hospedagem, software e outros). Cadastre seus serviços, acompanhe quanto gasta por mês e por ano e saiba quais assinaturas estão ativas ou canceladas.

**Funcionalidades** <br>
Dashboard com gasto mensal, quantidade de assinaturas ativas e canceladas <br>
Gasto anual estimado, calculado a partir das assinaturas ativas <br>
Cadastro, edição e exclusão de assinaturas (CRUD completo) <br>
Campos: nome do serviço, categoria, valor mensal, data de vencimento, forma de pagamento e status <br> 
Pesquisa em tempo real na tabela de assinaturas <br> 
Confirmação antes de excluir um registro <br> 
Layout responsivo com menu lateral <br> 
<br>
**Tecnologias** <br> 
PHP (PDO com prepared statements) <br> 
MySQL <br> 
Bootstrap 5.3 e Bootstrap Icons <br> 
JavaScript <br> 
CSS <br>
